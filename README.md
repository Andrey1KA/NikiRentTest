# Дашборд обращений гостей NikiRent

Рабочая страница для руководителя: статистика обращений гостей за выбранный месяц и отдельный список нерешённых бытовых вопросов.

Сервер, база и вход по паролю не используются. Таблица читается в браузере, поэтому дашборд открывается по ссылке без регистрации и дополнительных доступов.

## Что сделано

На одной странице два блока.

**Статистика**

- Общее число обращений за выбранный месяц.
- Количество и доля по каждой категории.
- Горизонтальная диаграмма тех же категорий.
- Переключатель месяцев. В списке только те месяцы, которые есть в таблице.

**Нерешённые бытовые вопросы**

- Отдельная таблица, которая не зависит от выбранного месяца.
- В ней дата поступления, квартира, суть проблемы, ответственный и статус.
- Сверху показано, сколько таких вопросов сейчас.
- Самые старые вопросы стоят первыми.

**Откуда берутся данные**

При открытии страница считает вложенную копию таблицы `public/data/appeals.xlsx`. Кнопка «Загрузить файл» принимает новый Excel или CSV и сразу пересчитывает статистику и список нерешённых вопросов. Файл в проекте при этом не перезаписывается: загрузка действует только в открытой вкладке. Если новый файл прочитать не удалось, на экране остаются прежние цифры и показывается ошибка.

## Как считаются цифры

В расчёт попадает строка, у которой заполнена дата поступления. Подписи месяцев вроде «Октябрь» и «Ноябрь» обращениями не считаются. Месяц берётся из даты обращения, а не из этой подписи.

Заголовки ищутся по названиям колонок:

- дата поступления вопроса;
- квартира/дом;
- коротко суть вопроса;
- категория;
- ответственный;
- статус.

**Текущий календарный месяц** считается с 1-го числа по сегодняшний день. Обращения с датой позже сегодняшнего дня в этот срез не входят. **Прошедший месяц** показывается целиком.

Доля категории — это процент от числа обращений в выбранном срезе, с одним знаком после запятой.

**Нерешённым бытовым вопросом** считается обращение категории `🔧быт.вопрос`, у которого статус не `решен`. Пустой статус и статус «отложен» тоже нерешённые. Сравнение статуса не зависит от регистра: «Решен» и «решен» считаются закрытыми. Вопросы других категорий, даже с пустым статусом, в этот список не попадают.

На копии таблицы из задания это даёт такие контрольные цифры, если сегодня 19 ноября 2026:

| Период | Обращений |
| --- | ---: |
| Октябрь 2026, весь месяц | 15 |
| Ноябрь 2026, с 1 по 19 | 13 |
| Нерешённый быт, все месяцы | 3 |

Три нерешённых вопроса: БЗах 142-121 от 01.10.2026, Гер 29/5 от 14.10.2026, Триумф от 11.11.2026 со статусом «отложен».

## Как открыть локально

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

После запуска откройте http://localhost:3000

Проверка контрольных цифр по вложенной таблице:

```bash
npm run check-data
```

## Как выложить на Vercel

Проект — обычное приложение Next.js. Отдельный бэкенд подключать не нужно.

1. Залейте папку в Git. В репозиторий не попадают `node_modules`, `.next` и `vacancy.md`.
2. На Vercel создайте проект из этого репозитория. Платформа сама определит Next.js.
3. Команду сборки оставьте `next build`. Переменные окружения не требуются.
4. После деплоя откройте выданную ссылку. Проверяющий увидит дашборд без регистрации.

Копия таблицы `public/data/appeals.xlsx` уходит вместе с сайтом, поэтому цифры есть сразу после открытия.

Пустая квартира в таблице допустима: на экране она показывается как «—». Пустой статус в списке нерешённых показывается как «не указан».

## Что сознательно не делалось

По условиям задания не подключались Google Таблица, сервер, база, авторизация и CRM. Загрузка нового файла пересчитывает экран и не записывает изменения обратно в таблицу проекта.
